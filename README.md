Provides Python scripts for analyzing the radial distribution function (RDF) , density of states (DOS), crystal orbital Hamilton population analysis and electron localization function partitioning.

The RDF and DOS are calculated directory from VASP structural data files (POSCAR) and VASP output files (vaspout.h5), respectively. 

Crystal orbital Hamilton population analysis and electron localization function partitioning are analzyed prior with LOBSTER and critic2, respectively.
